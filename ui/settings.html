Rule lists

BNet mutes whatever its rule lists describe, the way an ad blocker uses filter lists. Each list is a plain-text file with one rule per line.

Add a list

My rules

    Rule syntax 
    ! A comment. Header lines: ! Title:, ! Version:, ! Expires: 1 day

phrase racism 3 go back to your country           ! plain words; any spacing matches
phrase extremism,religion 3 /holo\s*hoax/         ! a regex between slashes
slur lgbtq 3 troon, tranny                        ! disguised spellings are caught automatically
group religion muslims, jews, christians          ! who a hateful claim can be about
claim 3 /are\s+(?:vermin|rats)/ $tag=dehumanising ! words after a group: "muslims are vermin"
before 3 /deport\s+all/                           ! words before a group: "deport all migrants"
allow /chink\s+in\s+the\s+armou?r/                ! never mute this
define BAD (?:vermin|rats)                        ! reusable piece, used later as {BAD}

    Severity: 3 unmistakable, 2 clear hate, 1 borderline (only muted on Strict). Kinds: racism, religion, sexism, lgbtq, ableism, slurs, dehumanising, extremism, political. Options at the end of a line: $tag= adds kinds, $for= limits a claim to some groups, $inword lets a slur match inside a word, $raw drops word edges.

    Version .

    BNet reads X as you scroll and mutes hateful and extremist speech, leaving the rest of the post untouched.

    Everything happens on this computer. Text matching and image reading both run locally, and nothing you read is sent anywhere.
